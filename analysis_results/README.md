# Experimental analysis results

This directory contains processed data, plots, and CSV files generated from
the experimental ROS 2 bag recordings.

## used_in_thesis

Contains the processed results used in the analysis presented in the
Master's Thesis:

- `static_01`
- `linear_02`
- `rotation_left_90_01`
- `rotation_right_90_01`
- `square_01`
- `manual_navigation_01`

## additional_tests

Contains processed results from development or backup experiments that were
not directly used in the final thesis results.

The file `experimental_summary.csv` contains a general summary of the
experimental recordings.
