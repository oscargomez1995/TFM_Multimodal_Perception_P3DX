# Experimental datasets

This directory contains the ROS 2 bag files recorded during the experimental
validation of the Pioneer P3-DX platform.

## used_in_thesis

Contains the datasets used for the analysis and results presented in the
Master's Thesis:

- `static_01`: static test.
- `linear_02`: linear motion test.
- `rotation_left_90_01`: 90° left rotation test.
- `rotation_right_90_01`: 90° right rotation test.
- `square_01`: square trajectory test.
- `manual_navigation_01`: manual navigation test.

## additional_tests

Contains preliminary, development, backup, and additional experimental
recordings that were not directly used for the final results presented in
the thesis.

These datasets are preserved as complementary experimental material.
